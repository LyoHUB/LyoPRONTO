Testing

To install test dependencies, run 

pip install .[dev]
inside the LyoPRONTO directory (next to pyproject.toml).

Execute 

pytest ./tests
to run all the tests; some that use papermill to generate documentation notebooks are marked, and you can exclude those with 
pytest ./tests -m "not notebook"

Notes on contributing & maintenance

There is a GitHub Action on this repo which will automatically build the documentation (which uses Material for MkDocs with mike for versioning). This action triggers on push to main (which creates a dev section of the docs) and on publishing a release (which creates a numbered version of the docs).

To clear out versions of the docs 

git fetch 
mike delete pr-### # replace with correct PR number
git switch gh-pages
git push origin gh-pages
Fo This could theoretically be automated but I decided against this for now. In the long run, it may be worth not generating PR versions of the docs if this is burdensome.
